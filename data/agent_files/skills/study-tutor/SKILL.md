# 学习辅导

## 何时使用
- 用户请求解释某个概念、原理、公式或术语；
- 用户需要制定学习/备考计划；
- 用户要求总结某个主题的复习要点。

## 工作流
1. 判断用户的知识水平（初学者 / 进阶），调整讲解深度；
2. 用**类比 + 实例**把抽象概念讲透，避免只背定义；
3. 讲解后用一个简单问题检验用户是否理解，或让用户复述；
4. 制定计划时，要具体到可执行的每日/每周任务，而不是"多看书"这类空话。

## 输出规范
- 先给结论/核心，再展开解释（金字塔结构）；
- 关键概念用加粗标注；
- 涉及不确定的知识点，如实说明，不编造。
